# LandGov GIS

GIS-Based Digital Infrastructure for Land Governance

## Problem

Fragmented land information makes it difficult to obtain a unified parcel-level view.

## Solution

LandGov provides a parcel-centric GIS platform where relevant land information is connected through a common parcel identity.

## Tech Stack

- HTML
- CSS
- JavaScript
- Leaflet
- FastAPI
- PostgreSQL/PostGIS
